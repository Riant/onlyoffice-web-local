# 字体缩放功能评估计划

## 背景

国内公文文档（俗称"红头文件"）需要又瘦又高的红色标题头，一般使用 Word 的字体缩放功能实现：

* 上下拉伸、左右压缩

* 在一行内显示下长长的标题文本

## 评估目标

评估 WASM 版 OnlyOffice 中字体缩放功能的可行性。

## 分析过程

### 1. 渲染架构分析

**Canvas 渲染架构**：

* **Canvas 2D 上下文**：通过 `canvas.getContext("2d")` 获取，是纯 JavaScript 实现

* **字体渲染**：通过 WASM FreeType 完成字形生成，然后绘制到 Canvas 上

* **变换矩阵**：渲染器支持 2D 变换矩阵

### 2. 关键代码发现

#### 2.1 变换矩阵支持

在 `sdk-all.js` 第 130 行和 161 行发现：

```javascript
case 130: d.transform(e.rf(), e.rf(), e.rf(), e.rf(), e.rf(), e.rf()); break;
case 161: d.transform(e.rf(), e.rf(), e.rf(), e.rf(), 0, 0); break;
```

这表明渲染器支持变换矩阵，可以用于字体缩放。

#### 2.2 字体渲染流程

```javascript
case 80: // 文本渲染
    t = e.l9();
    x = !0 === n ? e.l9() : 65535;
    // ... 计算位置
    AscFonts.KWc = !0;
    d.jX(A, H, String.fromCharCode(t)); // 绘制字符
    AscFonts.KWc = !1;
```

### 3. 问题分析

#### 3.1 渲染层面

**Canvas 渲染是 JavaScript 实现的**，支持变换矩阵。理论上可以实现字体缩放。

#### 3.2 文档解析层面

**关键问题**：需要确认 OnlyOffice 是否解析了 Word 文档中的字体缩放参数。

Word 文档中的字体缩放信息存储在：

* `w:rPr` 元素下的 `w:w` 属性（字符宽度缩放）

* 值是百分比，如 `w:w="50"` 表示 50% 宽度

### 4. 可行性评估

#### 方案一：检查现有支持

**步骤**：

1. 创建一个包含字体缩放的 Word 文档
2. 用 OnlyOffice 打开，检查是否正确渲染
3. 如果不支持，分析解析代码

#### 方案二：修改文档解析和渲染

**如果现有不支持，需要**：

1. **文档解析层**：

   * 找到 OOXML 解析代码

   * 添加 `w:w` 属性的解析

   * 将缩放参数保存到文档模型

2. **渲染层**：

   * 在渲染文本时，检查缩放参数

   * 应用变换矩阵：`transform(scaleX, 0, 0, 1, 0, 0)`

   * 其中 `scaleX` 是缩放比例

### 5. 结论

**Canvas 渲染是 JavaScript 实现的，支持变换矩阵，理论上可以实现字体缩放功能。**

**关键问题**：需要确认 OnlyOffice 是否已经解析了 Word 文档中的字体缩放参数。

**推荐步骤**：

1. **首先测试**：创建一个包含字体缩放的 Word 文档，用 OnlyOffice 打开，检查是否正确渲染
2. **如果支持**：无需修改
3. **如果不支持**：需要修改文档解析和渲染代码

### 6. 后续工作

1. 创建测试文档，验证现有支持情况
2. 如果不支持，搜索 `w:w` 或 `textScale` 相关的解析代码
3. 修改解析逻辑，保存缩放参数
4. 修改渲染逻辑，应用变换矩阵
